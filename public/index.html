Nova Arquitetura Verificando WebGPU

WebGPU (Origami)

Segunda implementação independente baseada no projeto GeneralsX Web (origami-ltd/wasm-generals), desenvolvida sobre WebGPU e multi-threading via SharedArrayBuffer.

  • ⚡ Pipeline WebGPU: Renderização moderna com shaders compilados via DXVK e alocação de heap WASM de 2 GiB.
  • ⚡ Worker Multi-thread: Simulação desacoplada da thread de renderização para maior taxa de quadros e tolerância a abas em segundo plano.
  • ⚡ Streaming Sob Demanda: Acesso direto via File System Access API para montar pastas originais do jogo.
  • ⚡ Origami Build 46382a3: Versão upstream congelada e instalada diretamente no domínio Captalvo.
Requisitos: Exige suporte nativo a WebGPU no navegador (Google Chrome 113+, Microsoft Edge 113+) e no mínimo 8 GB de RAM recomendada.
